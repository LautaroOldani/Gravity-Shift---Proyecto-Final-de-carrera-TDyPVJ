# Gravity Shift - Proyecto Final de Carrera (Preproducción)

Repositorio correspondiente al desarrollo del proyecto de videojuegos **Gravity Shift** para la carrera de Diseño y Programación de Videojuegos.

Este espacio contiene el **Game Design Document (GDD)** del proyecto, un videojuego desarrollado de manera individual que explora mecánicas de cambio de gravedad.

## 📂 Contenido del Repositorio

* **`GDD.md`**: Documento principal del Game Design Document (GDD), detallando el high concept, la visión inicial, las mecánicas core y la estructura del proyecto.
* **`imagenes/`**: Carpeta que almacena los recursos visuales, el concept art de preproducción y el diseño de la interfaz utilizados en la documentación.
